---
title: Discord Bot Commands
description: Slash commands the Omniplex tracking bot exposes on a listed server.
---

Omniplex's tracking bot manages your server's listing directly from
Discord. All commands are slash commands, and each requires the bot to
already be a member of the server.

<Callout type="info">
  To list a server for the first time, use **Add a Server** on the site
  instead of a Discord command. See the [Getting Started](https://omniplex.gg/kb/basics/getting-started)
  guide on the main site.
</Callout>

## `/update`

Updates a specific part of your server's listing (which "pane" to update is
chosen when you run the command) without leaving Discord. Requires the
`Edit Servers` permission on the listing. Currently has two panes:

- `basic`: opens a modal for the short and long description.
- `invite`: opens a wizard asking for a new invite link.

## `/delete`

Removes your server's listing. Requires the `Delete Servers` permission on
the listing, and asks for confirmation before deleting anything.

## `/leaderboard`

Shows the server's vote leaderboard. Takes an optional `limit` (how many
results to show, defaults to 10).

<Callout type="warn">
  The `filter_onlycurrmembers` option is not currently functional. The bot
  doesn't have the Discord intent needed to check server membership, so
  setting it returns an error instead of filtering results.
</Callout>

## `/stats`

Shows the bot's own stats (uptime, version, environment).

Popplio is the REST API behind Omniplex. Everything the site does (listing
bots and servers, votes, teams, webhooks) goes through it, and it's open for
anyone to build against.

## Base URL

```
https://api.omniplex.gg
```

## Authentication

Authenticated requests send a token in the `Authorization` header, either on
its own or prefixed with what it belongs to:

```
Authorization: Bot <token>
```

Each endpoint below says which kinds of token it accepts. See
[Authentication](/docs/developer/authentication) for which token to use, and
the [SDKs](/docs/sdks) if you'd rather not make these requests yourself.

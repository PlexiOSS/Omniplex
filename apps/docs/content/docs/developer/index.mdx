This section covers the mechanics of building against Popplio: how auth
and permissions work, what the rate limits are, and how to report stats,
handle votes, and receive webhooks. For the endpoints themselves, see the
[API Reference](/docs/api-reference). For ready-made libraries, see the
[SDKs](/docs/sdks).

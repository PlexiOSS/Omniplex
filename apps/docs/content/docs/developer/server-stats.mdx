---
title: Posting Server Stats
description: Self-reporting your server's member count instead of waiting on the automatic sync.
---

Every listed server's member and online counts are normally kept in sync automatically: Infernoplex, the tracking bot, polls Discord every 30 minutes and updates them for you, with no setup. If you want more control over when those numbers update, or your server doesn't have Infernoplex in it, you can post them yourself instead.

## Endpoint

```
POST /servers/stats
```

Send an API token for your server in `Authorization`, as `<token>` or `Server <token>`. Create one under **API sessions** in the server's dashboard (see [Authentication](/docs/developer/authentication)). Every [SDK](/docs/sdks) has a `postServerStats` / `post_server_stats` method that does this for you.

## Body

Every field is optional. Only send what you actually have: an omitted field keeps whatever value was last posted rather than being reset to zero.

```json
{
  "total_members": 1234,
  "online_members": 456
}
```

| Field | Type | Notes |
|---|---|---|
| `total_members` | number | Total member count. |
| `online_members` | number | Online member count. |

## Self-managed stats

Posting to this endpoint at all, even with an empty body, flips your server into **self-managed** mode: Infernoplex's automatic 30-minute sync stops overwriting `total_members`/`online_members` for your server from that point on (it still keeps your server's icon in sync either way). This is currently one-way: there's no endpoint to switch back to automatic syncing once you've posted your own stats. If you need that reversed, reach out rather than assuming it'll revert on its own.

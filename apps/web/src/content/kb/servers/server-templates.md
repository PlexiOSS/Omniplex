A server template is a copy of a Discord server's channels, roles and permissions, without its members or messages. Anyone can use one to start a new server with the same setup. [Server Templates](/templates) collects templates people have shared, so you can find a ready-made setup instead of building one from scratch.

## Using a template

Open a template and click **Use template**. Discord opens and asks which name and icon to give the new server, then builds it with the template's channels and roles. Before you click, the template's page shows every channel and role it includes, how many times it's been used on Discord, and what people thought of it.

## Sharing your own

You need a template on Discord first:

1. In Discord, open **Server Settings** in the server you want to share, then **Server Template**.
2. Create the template, or sync an existing one, and copy its link.
3. On Omniplex, go to [Submit a template](/templates/add) and paste the link or the code after `discord.new/`.
4. Write a short description (up to 150 characters), pick tags, and mark it NSFW if the server it builds is meant for adults.

The name comes from Discord, so it always matches the template itself. Once it's submitted, you're taken straight to its page.

## Keeping it up to date

A template on Discord is a snapshot. When you change your server, the template doesn't change until you sync it in Discord.

Omniplex checks every template against Discord about once a day and picks up its current name, channels, roles and usage count. To update it straight away, go to **Dashboard > Templates**, click **Manage**, open **Sync** and click **Sync now**.

The Sync page also tells you:

- **Unsynced changes**: your server has changed since the template was last synced on Discord. Sync the template in Discord's **Server Template** settings first, then sync on Omniplex.
- **Deleted on Discord**: the template no longer exists on Discord, so nobody can use it. It's hidden from the templates list but not deleted. If you create the template again with the same code, the next sync brings it back. Otherwise, submit your new template and delete the old listing.

## Giving it an icon

Templates show a default icon until you add your own. In **Manage**, open **Icon** and upload a WebP, PNG, JPEG or GIF up to 5MB. It's cropped to a square and shown on the template's card and page. You can replace or remove it at any time.

## Editing or deleting

Everything about your template lives in **Dashboard > Templates > Manage**:

- **Details**: change the description, tags and NSFW setting.
- **Icon**: upload, replace or remove the icon.
- **Sync**: refresh it from Discord and see whether it's up to date.
- **Danger zone**: delete the listing. This removes it from Omniplex, along with its likes and reviews. The template on Discord isn't touched.

## Likes and reviews

Anyone signed in can like or dislike a template, and leave a review. Reviews follow the same rules as reviews on bots and servers. If a template breaks the [Listing Rules](/kb/servers/listing-rules), report it like any other listing.

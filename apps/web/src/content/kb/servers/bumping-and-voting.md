Once your server is listed and approved, members can help it climb Omniplex straight from Discord with two commands from the Omniplex tracking bot.

## /bump

`/bump` moves your server to the top of the **Recently bumped** list, which appears as a tab on the home page and as a sort option when browsing servers.

- Anyone in the server can bump it, once every **2 hours** per server. If someone bumped it recently, the command tells you when the next bump is available.
- Only public servers that have been approved can be bumped.
- Bumping doesn't change your votes, ranking or the other sort orders. It only affects **Recently bumped**.

After each bump the bot shows the server's top bumpers for the last 30 days. Your server page shows when it was last bumped, how many bumps it got in the last 30 days and the same leaderboard.

## /vote

`/vote` votes for the server you're in, without opening the website.

- It follows the same rules as voting on the site: the same cooldown, the same weekend bonus, and votes count toward rankings, the voter leaderboard and vote credits.
- You need to have signed in to Omniplex with Discord at least once. If you haven't, the bot gives you a link to do that.
- If the server requires a captcha to vote, the bot gives you a link to vote on the website instead.
- Banned and vote-banned accounts can't vote from Discord either.

## Tips

- Pin a message or set up a reminder in your server asking members to `/bump` and `/vote`. Regular bumps keep your server near the top of Recently bumped.
- Bumping with several accounts to farm the leaderboard breaks the [listing rules](/kb/servers/listing-rules) the same way vote manipulation does.
